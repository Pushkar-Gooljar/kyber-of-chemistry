# Transition Elements

## Definition

>[!info] Definition: Transition Element
>d-block element which forms one or more stable ions with incomplete d orbitals.

![Transition elements are found in the d-block of the Periodic Table|500](https://s3.eu-west-2.amazonaws.com/elements.cognitoedu.org/1efe9d5c-91b6-46cc-9f78-f0caa3c00042/periodic-table-d-block.png)

>[!warning] Exceptions in the First Row (Period 4)
>**Scandium ($\ce{Sc}$)** 
>- Forms only one stable ion, $\ce{Sc^3+}$. 
>- Its electronic configuration is $\mathrm{[Ar]3d^0}$.
>- Since the d-subshell is empty, it is **not** a transition element.
>  
>**Zinc ($\ce{Zn}$)**
>- Forms only one stable ion, $\ce{Zn^2+}$.
>- Its electronic configuration is $\mathrm{[Ar]3d^{10}}$.
>- Since the d-subshell is completely full it is **not** a transition element.

## Electron Configuration
>[!warning] Anomalies in E.C.
>1. **Chromium ($\ce{Cr}$):** $\mathrm{[Ar]3d^54s^1}$ instead of $\mathrm{[Ar]3d^44s^2}$
>2. **Copper ($\ce{Cu}$):** $\mathrm{[Ar]3d^{10}4s^1}$ instead of $\mathrm{[Ar]3d^94s^2}$
> 
>**Recall:** This happens because half-filled and fully-filled d-subshells offer extra thermodynamic stability.

>[!important] E.C. of Ions
>When forming positive ions, electrons in the $\mathrm{4s}$ subshell are always lost first, followed by the $\mathrm{3d}$ subshell.
>
>**Recall:** The $\mathrm{4s}$ subshell is at a higher energy level.
