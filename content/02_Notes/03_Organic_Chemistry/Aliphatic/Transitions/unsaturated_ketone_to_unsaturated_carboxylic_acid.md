# Reaction Summary
>[!tip] Reagents
>- Step 1: $\ce{I2(aq)}$ / $\ce{NaOH(aq)}$
>- Step 2: dilute $\ce{H2SO4}$ / $\ce{HCl}$

>[!tip] Conditions
>- Step 1: warm
>- Step 2: room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CH=CH-CO-CH3 + 3I2 + 4OH- -> CHI3 + R-CH=CH-COO- + 3I- + 3H2O}$$
>
>$$\ce{R-CH=CH-COO- + H+ -> R-CH=CH-COOH}$$

>[!summary] By-Products
>- $\ce{CHI3}$
>- $\ce{I-}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Step 1: pale yellow precipitate


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Iodoform reaction then **acidification** — the alkaline step only gives the carboxylate.
>- Product has **one fewer carbon** than the methyl ketone.
>- Hot conc. $\ce{KMnO4}$ would be wrong: it cleaves the C=C.
