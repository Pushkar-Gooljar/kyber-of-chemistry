# Reaction Summary
>[!tip] Reagents
>- Aqueous iodine, $\ce{I2(aq)}$
>- Aqueous sodium hydroxide, $\ce{NaOH(aq)}$

>[!tip] Conditions
>- Warm

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{RCOCH3 + 3I2 + 4OH- -> RCOO- + CHI3 + 3I- + 3H2O}$$

>[!summary] By-Products
>- Tri-iodomethane $\ce{CHI3}$
>- Iodide ion $\ce{I-}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- **Pale yellow precipitate** of $\ce{CHI3}$


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Iodoform reaction — only **methyl ketones** ($\ce{CH3CO-}$) react.
>- The C–C bond between C=O and $\ce{CH3}$ breaks: $\ce{CH3}$ ➔ $\ce{CHI3}$, the rest ➔ carboxylate with **one fewer carbon** than the ketone.
>- Alkaline conditions ➔ **carboxylate ion**, not the acid. Acidify to get $\ce{RCOOH}$.
>- Mechanism not required at 9701.
