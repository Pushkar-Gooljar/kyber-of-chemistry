# Reaction Summary
>[!tip] Reagents
>- Hydrogen gas, $\ce{H2}$
>- (1 mol $\ce{H2}$)

>[!tip] Conditions
>- Heat (~150 °C)

>[!tip] Catalyst 
>- Nickel, $\ce{Ni}$ (or Pt/Pd)



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CH=CH-CO-R' + H2 -> R-CH2-CH2-CO-R'}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Catalytic hydrogenation reduces the non-polar C=C in preference to C=O; excess $\ce{H2}$ would reduce both.
>- $\ce{NaBH4}$ would do the **opposite** (reduce C=O only).
