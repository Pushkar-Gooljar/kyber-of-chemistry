# Reaction Summary
>[!tip] Reagents
>- Hydrogen gas, $\ce{H2}$
>- (1 mol $\ce{H2}$ per C=C)

>[!tip] Conditions
>- Heat (~150 °C)

>[!tip] Catalyst 
>- Nickel, $\ce{Ni}$ (or Pt/Pd)



# Chemical Equation
>[!summary] Equation
>$$\ce{CH2=CH-CHO + H2 -> CH3CH2CHO}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Catalytic hydrogenation reduces the C=C; with **limited** $\ce{H2}$ the C=O is left. Excess/prolonged hydrogenation would also reduce the C=O ➔ primary alcohol.
>- $\ce{NaBH4}$ is **no use** here — it reduces C=O, not C=C.
>- Hydrogenation is **not** electrophilic addition — call it addition/catalytic hydrogenation.
