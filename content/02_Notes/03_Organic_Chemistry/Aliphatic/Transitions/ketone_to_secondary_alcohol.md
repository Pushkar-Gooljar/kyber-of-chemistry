# Reaction Summary
>[!tip] Reagents
>- Sodium tetrahydridoborate, $\ce{NaBH4}$

>[!tip] Conditions
>- Aqueous/alcoholic solution, room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CO-R' + 2[H] -> R-CH(OH)-R'}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Ketones always reduce to **secondary** alcohols.
>- $\ce{LiAlH4}$ in dry ether also works.
