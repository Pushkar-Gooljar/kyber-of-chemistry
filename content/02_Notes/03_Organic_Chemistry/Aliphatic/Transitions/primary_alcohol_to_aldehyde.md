# Reaction Summary
>[!tip] Reagents
>- Acidified potassium dichromate(VI), $\ce{K2Cr2O7}$ / dilute $\ce{H2SO4}$

>[!tip] Conditions
>- Heat and **distil immediately**

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{RCH2OH + [O] -> RCHO + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- '**Distil** (the aldehyde off) as it forms' is the mark — the aldehyde has a lower b.p. (no H-bonding) so it escapes before further oxidation.
>- Reflux instead ➔ carboxylic acid.
