# Reaction Summary
>[!tip] Reagents
>- Aqueous iodine, $\ce{I2(aq)}$
>- Aqueous sodium hydroxide, $\ce{NaOH(aq)}$

>[!tip] Conditions
>- Warm

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{CH3CHO + 3I2 + 4OH- -> CHI3 + HCOO- + 3I- + 3H2O}$$

>[!summary] By-Products
>- Methanoate ion $\ce{HCOO-}$
>- Iodide ion $\ce{I-}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- **Pale yellow precipitate** of tri-iodomethane $\ce{CHI3}$ (antiseptic smell)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- The **iodoform (tri-iodomethane) test**: positive for $\ce{CH3CO-}$ groups and for $\ce{CH3CH(OH)-}$ (which is first oxidised to $\ce{CH3CO-}$).
>- **Ethanal is the only aldehyde** that gives a positive result.
>- The $\ce{C-C}$ bond next to C=O is broken: the chain loses one carbon ($\ce{CH3}$ ➔ $\ce{CHI3}$).
>- Mechanism is **not required** at 9701 — describe it as substitution of the three CH₃ hydrogens by I, then hydrolysis/cleavage of the C–C bond.
