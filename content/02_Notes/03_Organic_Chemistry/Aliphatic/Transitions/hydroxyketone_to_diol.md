# Reaction Summary
>[!tip] Reagents
>- Sodium tetrahydridoborate, $\ce{NaBH4}$

>[!tip] Conditions
>- Aqueous/alcoholic solution, room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{HO-R-CO-R' + 2[H] -> HO-R-CH(OH)-R'}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- The ketone becomes a **secondary** alcohol; the existing OH is untouched.
>- Check for a new chiral centre — reduction of an unsymmetrical ketone gives a racemic product at that carbon.
