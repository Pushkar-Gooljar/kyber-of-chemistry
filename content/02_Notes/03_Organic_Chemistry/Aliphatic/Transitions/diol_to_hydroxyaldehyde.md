# Reaction Summary
>[!tip] Reagents
>- Acidified $\ce{K2Cr2O7}$ (limited amount)

>[!tip] Conditions
>- Heat and **distil immediately**

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{HOCH2CH2OH + [O] -> HOCH2CHO + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Only **one** primary OH is oxidised (1 mol [O]) ➔ 2-hydroxyethanal.
>- Distillation is required to stop at the aldehyde stage.
>- In practice selectivity is poor — this is a 'paper' step, typical of synthesis-route questions.
