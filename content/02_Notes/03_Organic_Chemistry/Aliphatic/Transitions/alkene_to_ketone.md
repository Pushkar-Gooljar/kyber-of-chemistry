# Reaction Summary
>[!tip] Reagents
>- Concentrated acidified potassium manganate(VII), $\ce{KMnO4}$ / $\ce{H2SO4}$

>[!tip] Conditions
>- Hot, heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{R2C=CR2 + 2[O] -> 2R2C=O}$$

>[!summary] By-Products
>- Depends on the other alkene carbon: $\ce{RCH=}$ ➔ $\ce{RCOOH}$; $\ce{CH2=}$ ➔ $\ce{CO2 + H2O}$

# Observations
>[!example] Observations 
>- Purple solution turns colourless ($\ce{MnO4-}$ ➔ $\ce{Mn^2+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- **Oxidative cleavage** — the C=C breaks completely.
>- A ketone only forms from an alkene carbon with **two alkyl groups and no H** ($\ce{R2C=}$).
>- Exams use this backwards: identify the products to deduce the position of C=C in the original alkene.
>- Contrast with **cold, dilute** acidified $\ce{KMnO4}$ ➔ diol (no cleavage).
