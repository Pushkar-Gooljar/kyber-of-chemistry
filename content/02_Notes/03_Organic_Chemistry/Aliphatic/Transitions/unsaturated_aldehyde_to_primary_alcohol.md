# Reaction Summary
>[!tip] Reagents
>- **Excess** hydrogen gas, $\ce{H2}$

>[!tip] Conditions
>- Heat (~150 °C)

>[!tip] Catalyst 
>- Nickel, $\ce{Ni}$ (or Pt/Pd)



# Chemical Equation
>[!summary] Equation
>$$\ce{CH2=CH-CHO + 2H2 -> CH3CH2CH2OH}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- **Both** π bonds must be reduced. $\ce{H2/Ni}$ reduces C=C **and** C=O.
>- $\ce{NaBH4}$ and $\ce{LiAlH4}$ will **not** work — they only reduce C=O, leaving C=C (they give the *unsaturated* alcohol).
>- Equivalent: $\ce{CH2=CHCHO + 4[H] -> CH3CH2CH2OH}$.
