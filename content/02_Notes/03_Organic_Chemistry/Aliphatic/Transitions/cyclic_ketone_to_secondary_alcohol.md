# Reaction Summary
>[!tip] Reagents
>- Sodium tetrahydridoborate, $\ce{NaBH4}$

>[!tip] Conditions
>- Aqueous/alcoholic solution, room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{C6H10O + 2[H] -> C6H11OH}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Cyclic ketones always reduce to cyclic **secondary** alcohols (cyclohexanone ➔ cyclohexanol).
>- $\ce{LiAlH4}$ in dry ether also works; $\ce{H2/Ni}$ is not the expected answer for C=O.
