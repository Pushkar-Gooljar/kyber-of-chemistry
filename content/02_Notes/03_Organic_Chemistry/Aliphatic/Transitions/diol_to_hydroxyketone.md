# Reaction Summary
>[!tip] Reagents
>- Acidified $\ce{K2Cr2O7}$

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{(CH3)2C(OH)CH(OH)CH3 + [O] -> (CH3)2C(OH)COCH3 + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Example: 3-methylbutane-2,3-diol ➔ 3-hydroxy-3-methylbutan-2-one.
>- The **secondary** OH ➔ C=O; the **tertiary** OH is not oxidised and survives.
>- If the other OH were primary, reflux would oxidise it to $\ce{-COOH}$ — so the retained OH is normally tertiary (or the oxidant is limited).
