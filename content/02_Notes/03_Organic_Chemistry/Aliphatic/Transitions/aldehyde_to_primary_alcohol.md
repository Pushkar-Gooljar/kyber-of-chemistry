# Reaction Summary
>[!tip] Reagents
>- $\ce{NaBH4}$ (aqueous/alcoholic solution)
>- *or* $\ce{LiAlH4}$ in dry ether

>[!tip] Conditions
>- Room temperature (warm for $\ce{NaBH4}$ if needed)
>- $\ce{LiAlH4}$: dry conditions, then add water/dilute acid

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{RCHO + 2[H] -> RCH2OH}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- $\ce{NaBH4}$ is the standard, safer answer for aldehydes/ketones.
>- Mechanism: hydride ion $\ce{H-}$ acts as the nucleophile attacking the $\delta+$ carbonyl C, then protonation.
>- Aldehydes ➔ **primary** alcohols; ketones ➔ secondary alcohols.
