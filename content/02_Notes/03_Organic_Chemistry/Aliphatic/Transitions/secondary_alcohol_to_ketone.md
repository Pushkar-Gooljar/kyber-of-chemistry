# Reaction Summary
>[!tip] Reagents
>- Acidified potassium dichromate(VI), $\ce{K2Cr2O7}$ / dilute $\ce{H2SO4}$

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CH(OH)-R' + [O] -> R-CO-R' + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Ketones cannot be oxidised further, so reflux is safe and ensures complete conversion.
>- Tertiary alcohols: **no reaction** (stays orange) — no H on the C–OH carbon.
