# Reaction Summary
>[!tip] Reagents
>- Acidified potassium dichromate(VI), $\ce{K2Cr2O7}$ / dilute $\ce{H2SO4}$
>- *or* acidified potassium manganate(VII), $\ce{KMnO4}$ / dilute $\ce{H2SO4}$

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{RCHO + [O] -> RCOOH}$$

>[!summary] By-Products
>- None in the [O] equation ($\ce{Cr^3+}$ / $\ce{Mn^2+}$ from the oxidant)

# Observations
>[!example] Observations 
>- Orange ➔ green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)
>- *or* purple ➔ colourless ($\ce{MnO4-}$ ➔ $\ce{Mn^2+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- **Reflux** (not distillation) keeps the volatile aldehyde in contact with the oxidant until fully oxidised.
>- Ketones are **not** oxidised — the orange colour stays, so acidified dichromate distinguishes aldehydes from ketones.
