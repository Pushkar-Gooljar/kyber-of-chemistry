# Reaction Summary
>[!tip] Reagents
>- Aqueous iodine, $\ce{I2(aq)}$
>- Aqueous sodium hydroxide, $\ce{NaOH(aq)}$

>[!tip] Conditions
>- Warm

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{RCOCH3 + 3I2 + 4OH- -> CHI3 + RCOO- + 3I- + 3H2O}$$

>[!summary] By-Products
>- Carboxylate ion $\ce{RCOO-}$ (one C shorter)
>- Iodide ion $\ce{I-}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- **Pale yellow precipitate** of $\ce{CHI3}$ (antiseptic smell)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Same reaction as [[ketone_to_carboxylate_ion]], focusing on the $\ce{CHI3}$ product.
>- Positive **only for methyl ketones** $\ce{CH3CO-}$ (and ethanal, and alcohols with $\ce{CH3CH(OH)-}$).
