# Reaction Summary
>[!tip] Reagents
>- **Tollens' reagent:** Tollens' reagent — ammoniacal silver nitrate, $\ce{[Ag(NH3)2]+}$ (alkaline)
>- **Fehling's solution:** Fehling's solution — $\ce{Cu^2+}$ complexed in alkaline solution

>[!tip] Conditions
>- **Tollens' reagent:** Warm gently in a water bath (no naked flame)
>- **Fehling's solution:** Warm gently in a water bath

>[!tip] Catalyst 
>- None



# Chemical Equation
## Tollens' reagent
>[!summary] Equation
>$$\ce{RCHO + 2[Ag(NH3)2]+ + 3OH- -> RCOO- + 2Ag + 4NH3 + 2H2O}$$

>[!summary] By-Products
>- $\ce{Ag}$ (silver metal)
>- $\ce{NH3}$
>- $\ce{H2O}$

## Fehling's solution
>[!summary] Equation
>$$\ce{RCHO + 2Cu^2+ + 5OH- -> RCOO- + Cu2O + 3H2O}$$

>[!summary] By-Products
>- $\ce{Cu2O}$ (copper(I) oxide)
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- **Tollens' reagent:** Colourless solution ➔ **silver mirror** forms on the inside of the tube (or grey/black ppt)
>- **Fehling's solution:** **Blue** solution ➔ **brick-red precipitate** of $\ce{Cu2O}$


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Both reagents are **alkaline**, so the product is the **carboxylate ion** $\ce{RCOO-}$, not $\ce{RCOOH}$. Acidify separately (dilute $\ce{H2SO4}$/$\ce{HCl}$) to obtain the acid.
>- Ketones give **no reaction** with either — this is the standard aldehyde vs ketone distinguishing test.
>- Oxidising agent: $\ce{Ag+}$ is reduced to $\ce{Ag}$ (Tollens); $\ce{Cu^2+}$ is reduced to $\ce{Cu+}$ in $\ce{Cu2O}$ (Fehling's).
>- Simplified form accepted: $\ce{RCHO + [O] + OH- -> RCOO- + H2O}$.
