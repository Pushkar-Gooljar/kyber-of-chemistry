# Reaction Summary
>[!tip] Reagents
>- Hydrogen cyanide, $\ce{HCN}$

>[!tip] Conditions
>- Room temperature

>[!tip] Catalyst 
>- Trace $\ce{KCN}$ / $\ce{NaCN}$ (source of $\ce{CN-}$ nucleophile)



# Chemical Equation
>[!summary] Equation
>$$\ce{RCHO + HCN -> RCH(OH)CN}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- You **must** state the trace $\ce{KCN}$/$\ce{NaCN}$: $\ce{HCN}$ is a weak acid, so it provides too few $\ce{CN-}$ nucleophiles on its own.
>- Mechanism: $\ce{CN-}$ attacks the $\delta+$ carbonyl C ➔ alkoxide intermediate ➔ protonated by $\ce{HCN}$ (regenerating $\ce{CN-}$).
>- Chain extended by **one carbon**.
>- Planar C=O can be attacked equally from either side ➔ **racemic mixture** (no optical activity) whenever the product has a chiral centre (all aldehydes except methanal).
