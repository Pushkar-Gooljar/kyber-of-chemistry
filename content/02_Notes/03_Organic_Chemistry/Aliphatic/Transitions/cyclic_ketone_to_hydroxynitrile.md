# Reaction Summary
>[!tip] Reagents
>- Hydrogen cyanide, $\ce{HCN}$

>[!tip] Conditions
>- Room temperature

>[!tip] Catalyst 
>- Trace $\ce{KCN}$ / $\ce{NaCN}$ (source of $\ce{CN-}$ nucleophile)



# Chemical Equation
>[!summary] Equation
>$$\ce{C6H10O + HCN -> C6H10(OH)CN}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Same as for open-chain ketones: $\ce{CN-}$ attacks the $\delta+$ carbonyl carbon.
>- Cyclohexanone gives 1-hydroxycyclohexane-1-carbonitrile — **not chiral** (ring is symmetrical about that carbon). An unsymmetrical ring ketone (e.g. 2-methylcyclohexanone) would give a chiral product.
>- Must state trace $\ce{KCN}$/$\ce{NaCN}$.
