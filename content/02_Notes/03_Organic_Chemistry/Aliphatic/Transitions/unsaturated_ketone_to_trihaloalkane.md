# Reaction Summary
>[!tip] Reagents
>- Aqueous iodine, $\ce{I2(aq)}$
>- Aqueous sodium hydroxide, $\ce{NaOH(aq)}$

>[!tip] Conditions
>- Warm

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CH=CH-CO-CH3 + 3I2 + 4OH- -> CHI3 + R-CH=CH-COO- + 3I- + 3H2O}$$

>[!summary] By-Products
>- Unsaturated carboxylate ion
>- Iodide ion $\ce{I-}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- **Pale yellow precipitate** of $\ce{CHI3}$


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Needs a $\ce{CH3}$ **directly attached** to C=O.
>- The C=C is unaffected by alkaline iodine.
