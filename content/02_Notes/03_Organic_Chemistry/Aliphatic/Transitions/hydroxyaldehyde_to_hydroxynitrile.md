# Reaction Summary
>[!tip] Reagents
>- Hydrogen cyanide, $\ce{HCN}$

>[!tip] Conditions
>- Room temperature

>[!tip] Catalyst 
>- Trace $\ce{KCN}$ / $\ce{NaCN}$ (source of $\ce{CN-}$ nucleophile)



# Chemical Equation
>[!summary] Equation
>$$\ce{HO-R-CHO + HCN -> HO-R-CH(OH)CN}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- The product is really a **dihydroxy**nitrile — a new OH forms from the C=O.
>- Adds one carbon; new chiral centre ➔ racemic at that carbon.
>- Must state trace $\ce{KCN}$/$\ce{NaCN}$.
