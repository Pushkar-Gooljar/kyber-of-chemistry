# Reaction Summary
>[!tip] Reagents
>- Tollens' reagent (or Fehling's solution)
>- then dilute acid, e.g. $\ce{H2SO4(aq)}$

>[!tip] Conditions
>- Warm, then acidify

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{CH2=CHCHO + 2[Ag(NH3)2]+ + 3OH- -> CH2=CHCOO- + 2Ag + 4NH3 + 2H2O}$$
>
>$$\ce{CH2=CHCOO- + H+ -> CH2=CHCOOH}$$

>[!summary] By-Products
>- $\ce{Ag}$
>- $\ce{NH3}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Silver mirror (Tollens) / brick-red ppt (Fehling's)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- The C=C is **untouched** by Tollens/Fehling's — a mild oxidant is the safest answer.
>- Acidified $\ce{K2Cr2O7}$ under reflux is also accepted in many mark schemes (dichromate does not normally cleave C=C) — but **never** hot conc. $\ce{KMnO4}$, which would cleave the C=C.
>- Tollens/Fehling's give the carboxylate — acidify to get the acid.
