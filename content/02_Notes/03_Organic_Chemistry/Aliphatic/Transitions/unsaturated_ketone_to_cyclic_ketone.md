# Reaction Summary
>[!tip] Reagents
>- Hydrogen gas, $\ce{H2}$
>- (1 mol $\ce{H2}$)

>[!tip] Conditions
>- Heat (~150 °C)

>[!tip] Catalyst 
>- Nickel, $\ce{Ni}$ (or Pt/Pd)



# Chemical Equation
>[!summary] Equation
>$$\ce{C6H8O + H2 -> C6H10O}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Assumes a **cyclic** unsaturated ketone (cyclohex-2-enone ➔ cyclohexanone). Hydrogenation does **not** create a ring.
>- Limited $\ce{H2}$ so that only C=C is reduced; excess would also reduce C=O ➔ cyclohexanol.
