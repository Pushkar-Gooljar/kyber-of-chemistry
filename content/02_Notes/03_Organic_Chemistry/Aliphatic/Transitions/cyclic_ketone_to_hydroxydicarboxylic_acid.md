# Reaction Summary
>[!tip] Reagents
>- Concentrated acidified $\ce{KMnO4}$ (or $\ce{HNO3}$)

>[!tip] Conditions
>- Hot, heat under reflux (harsh)

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{C6H10O2 + 3[O] -> C6H10O5}$$
>
>$$\ce{\underset{3-hydroxycyclohexanone}{C6H10O2} + 3[O] -> \underset{2-hydroxyhexanedioic\ acid}{HOOC-CH(OH)-(CH2)3-COOH}}$$

>[!summary] By-Products
>- None in the [O] equation

# Observations
>[!example] Observations 
>- Purple solution turns colourless


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- **Not a standard single-step 9701 reaction** — only seen in 'unfamiliar reaction' deduction questions. Ketones are normally resistant to oxidation.
>- Under harsh conditions a cyclic ketone ring is cleaved next to C=O, giving a **dicarboxylic acid** with the same number of C atoms (e.g. cyclohexanone ➔ hexanedioic acid).
>- For a **hydroxy**dicarboxylic acid, the starting ketone must already carry an OH on a carbon that stays $\ce{CH(OH)}$ (e.g. 3-hydroxycyclohexanone above). Cleavage on the other side of C=O gives the isomer 3-hydroxyhexanedioic acid.
>- A secondary OH would itself oxidise under these conditions in reality — accept the deduction logic, not the practicality.
