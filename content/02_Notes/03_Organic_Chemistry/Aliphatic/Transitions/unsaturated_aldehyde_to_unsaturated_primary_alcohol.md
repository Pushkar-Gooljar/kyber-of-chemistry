# Reaction Summary
>[!tip] Reagents
>- Sodium tetrahydridoborate, $\ce{NaBH4}$

>[!tip] Conditions
>- Aqueous/alcoholic solution, room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{CH2=CH-CHO + 2[H] -> CH2=CH-CH2OH}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Classic trap: $\ce{NaBH4}$ supplies the nucleophile $\ce{H-}$, which attacks the $\delta+$ C of the **polar** C=O. The **non-polar, electron-rich** C=C repels nucleophiles, so it is left intact.
>- $\ce{H2/Ni}$ would reduce both — wrong reagent here.
