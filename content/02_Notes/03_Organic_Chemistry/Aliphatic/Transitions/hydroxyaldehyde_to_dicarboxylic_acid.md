# Reaction Summary
>[!tip] Reagents
>- Acidified $\ce{K2Cr2O7}$ in **excess**

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{HOCH2-R-CHO + 3[O] -> HOOC-R-COOH + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Needs **3 [O]**: 2 for $\ce{-CH2OH}$ ➔ $\ce{-COOH}$, 1 for $\ce{-CHO}$ ➔ $\ce{-COOH}$ — state **excess** oxidant.
>- Only works if the OH is **primary**; a secondary OH would give a ketone, a tertiary OH is unaffected.
