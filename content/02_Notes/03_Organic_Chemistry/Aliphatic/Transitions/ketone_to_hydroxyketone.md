# Reaction Summary
>[!tip] Reagents
>- Dilute aqueous $\ce{NaOH}$

>[!tip] Conditions
>- Room temperature

>[!tip] Catalyst 
>- $\ce{OH-}$ acts as a base catalyst



# Chemical Equation
>[!summary] Equation
>$$\ce{2CH3COCH3 <=> (CH3)2C(OH)CH2COCH3}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- **Aldol reaction of a ketone**: propanone ➔ 4-hydroxy-4-methylpentan-2-one. Same idea as [[aldehyde_to_hydroxyaldehyde]].
>- $\ce{OH-}$ removes an H from a $\ce{CH3}$ next to C=O; the carbanion attacks the $\delta+$ carbonyl C of a second molecule, forming a new **C–C bond**.
>- Not core syllabus — expect it only as an unfamiliar reaction to deduce.
>- An unsaturated ketone + steam/$\ce{H3PO4}$ also gives a hydroxyketone — see [[unsaturated_ketone_to_hydroxyketone]].
