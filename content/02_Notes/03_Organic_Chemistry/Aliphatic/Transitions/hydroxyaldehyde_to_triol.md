# Reaction Summary
>[!tip] Reagents
>- Sodium tetrahydridoborate, $\ce{NaBH4}$

>[!tip] Conditions
>- Aqueous/alcoholic solution, room temperature

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{(HO)2R-CHO + 2[H] -> (HO)2R-CH2OH}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- To end with a **triol** the starting material must be a **dihydroxy**aldehyde (e.g. 2,3-dihydroxypropanal ➔ propane-1,2,3-triol, glycerol).
