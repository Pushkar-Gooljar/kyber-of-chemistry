# Reaction Summary
>[!tip] Reagents
>- Acidified potassium dichromate(VI), $\ce{K2Cr2O7}$ / dilute $\ce{H2SO4}$

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{CH2=CH-CH(OH)-CH3 + [O] -> CH2=CH-CO-CH3 + H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- The C=C survives acidified dichromate; only $\ce{KMnO4}$ (cold dilute ➔ diol, hot conc. ➔ cleavage) would attack it.
