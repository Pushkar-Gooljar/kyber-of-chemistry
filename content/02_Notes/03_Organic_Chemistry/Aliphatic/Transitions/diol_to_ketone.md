# Reaction Summary
>[!tip] Reagents
>- Acidified $\ce{K2Cr2O7}$ (excess)

>[!tip] Conditions
>- Heat under reflux

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{CH3CH(OH)CH(OH)CH3 + 2[O] -> CH3COCOCH3 + 2H2O}$$

>[!summary] By-Products
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Orange solution turns green ($\ce{Cr2O7^2-}$ ➔ $\ce{Cr^3+}$)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Both OH groups must be **secondary** to give a (di)ketone — butane-2,3-diol ➔ butanedione.
>- Ketones are not oxidised further, so reflux is safe.
