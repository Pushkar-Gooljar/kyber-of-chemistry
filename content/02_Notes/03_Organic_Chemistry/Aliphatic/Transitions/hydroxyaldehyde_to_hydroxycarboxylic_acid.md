# Reaction Summary
>[!tip] Reagents
>- Tollens' reagent (or Fehling's solution)
>- then dilute acid, e.g. $\ce{H2SO4(aq)}$

>[!tip] Conditions
>- Warm, then acidify

>[!tip] Catalyst 
>- None



# Chemical Equation
>[!summary] Equation
>$$\ce{HO-R-CHO + 2[Ag(NH3)2]+ + 3OH- -> HO-R-COO- + 2Ag + 4NH3 + 2H2O}$$
>
>$$\ce{HO-R-COO- + H+ -> HO-R-COOH}$$

>[!summary] By-Products
>- $\ce{Ag}$
>- $\ce{NH3}$
>- $\ce{H2O}$

# Observations
>[!example] Observations 
>- Silver mirror (Tollens) / brick-red ppt (Fehling's)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- A **mild, selective** oxidant is needed: acidified dichromate under reflux would also oxidise a primary/secondary OH.
>- Tollens/Fehling's are alkaline, so the carboxylate forms first — **acidify** to get the acid.
>- If the OH is tertiary, acidified $\ce{K2Cr2O7}$ under reflux is also acceptable.
