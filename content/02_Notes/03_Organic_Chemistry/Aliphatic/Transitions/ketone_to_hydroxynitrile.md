# Reaction Summary
>[!tip] Reagents
>- Hydrogen cyanide, $\ce{HCN}$

>[!tip] Conditions
>- Room temperature

>[!tip] Catalyst 
>- Trace $\ce{KCN}$ / $\ce{NaCN}$ (source of $\ce{CN-}$ nucleophile)



# Chemical Equation
>[!summary] Equation
>$$\ce{R-CO-R' + HCN -> R-C(OH)(CN)-R'}$$

>[!summary] By-Products
>- None

# Observations
>[!example] Observations 
>- *No visible change* (colourless liquid/solution throughout)


# ⚠️ 9701 Exam Notes / Pitfalls
>[!warning]
>- Symmetrical ketones (e.g. propanone) give an **achiral** product; unsymmetrical ones (e.g. butanone) give a **racemic mixture**.
>- Must state trace $\ce{KCN}$/$\ce{NaCN}$.
>- Chain extended by one carbon; hydrolysis of the nitrile then gives a 2-hydroxycarboxylic acid.
